## Короткие ответы на вопросы

- **Где AI?** AI-инструменты помогали разрабатывать код и тесты. В продукте объяснения шаблонные, ранжирование лексическое; модельного инференса и Jev нет.
- **Почему первым не самый дешёвый?** Сначала сравниваем лексическую релевантность описания формату и пожеланию, затем цену и остальные критерии. Это не оценка качества работы и не вероятность успеха.
- **Можно бронировать?** Нет: результат помогает выбрать кандидатов для обсуждения. Доступность и итоговую смету нужно подтвердить у подрядчика.
- **Данные реальные?** Это анонимизированный набор организатора из 66 профилей, включая 13 синтетических. Метки синтетичности и подставленных значений видны в карточках.
- **Как проверить детерминизм?** Нажать «Популярная категория», затем «Подобрать подрядчиков» с теми же условиями. Порядок и текст повторятся.

## Перед выступлением

Запустить приложение по README, проверить три демо и сравнение дат. Выбрать масштаб браузера, при котором читаются объяснения. Не запускать сборку одновременно с dev-сервером в одной папке. Держать README открытым для вопроса о независимом запуске. Факт формальной отправки решения проверяется отдельно на платформе организатора.
